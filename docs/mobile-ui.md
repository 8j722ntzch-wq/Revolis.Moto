## Реализовано

- Opt-in класс `.mobile-ui`, отдельный stylesheet `src/styles/mobile-ui.css`; на главной импортируется только при ширине до 1287 px; в desktop UI Kit не загружается.
- Inter, контейнер 340 px при экране 390 px, кнопки S 38 px и поля 48 px, обычное/нажатое/недоступное состояния; общая палитра и токены переиспользуются.
- Существующие Button, TextField, Checkbox, StatusBadge, SectionHeading, FaqItem, ModelCard, BankCard и SiteFooter. Модель 340 × 592 px (допуск округления шрифта <1 px), банки 340 × 174 / 190 px, футер 390 × 1140 px. На узких экранах высота может увеличиться при переносе текста.
- MobileHeader 60 px, оригинальные SVG меню/закрытия, полноэкранный dialog с навигацией и телефонами. Нативное ограничение фокуса, Escape, возврат фокуса на кнопку, блокировка прокрутки фона и закрытие после выбора ссылки.
- FAQ использует утверждённые тексты и существующую анимацию 320 мс с reduced motion. Подпись «Открыть/Закрыть» видима постоянно.
- После просмотра главной 21.10.2026 естественный Hover ограничен Desktop от 1288 px и устройствами с мышью/трекпадом. На Mobile сохраняются нажатие и клавиатурный фокус; ModelCard/BankCard не поднимаются при касании. Фотография модели вписывается целиком с исходными пропорциями.
- Поля переиспользуют маску телефона; библиотека ничего не отправляет. Карточка модели демонстрационная; цены/банковские условия — образцы Figma. Неподтверждённые ссылки футера отключены.

## Проверка и продолжение

Astro check: 0 ошибок/предупреждений; build прошёл. Проверены браузерные ширины 320/360/390/430 px без переполнения, загрузка изображений, геометрия, меню/Escape/ссылки, поля и checkbox, FAQ. Физические iOS/Android не проверены. Размер 390 px — целевой дизайн; вне него проверена устойчивость компонентов, отдельного планшетного макета нет.

Экспорт: после сборки `npm run export:mobile`. Desktop и homepage не менялись. На следующем этапе собрать мобильную главную по свежим контекстам её секций; не применять `.mobile-ui` ко всей главной без адаптации секций и определения breakpoint. В частности, desktop finance использует высоту 294 px для центрирования якоря — на мобильной странице нужен другой расчёт. Диалоги заявок и backend остаются отдельным этапом.
