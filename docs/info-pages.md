# Контакты, 404 и политика — 21.10.2026

Реализованы /contacts/, /privacypolicy/ и стандартная Astro-страница /404.html. Все страницы адаптивные; мобильный переход — ниже 1288 px. Переиспользованы BaseLayout, SiteHeader, MobileHeader, SiteFooter и Button. InfoLayout объединяет оболочку новых страниц.

## Источники и решения

- Свежие высокоточные контексты и скриншоты шести рамок: Contacts Desktop 1:22666 / Mobile 1:22576; Privacy Desktop 1:22712 / Mobile 1:22621; 404 Desktop 1:22747 / Mobile 1:22656. Файл JkXOsnFvWZmMab1VYjVQAJ. Реестр design/info-pages.json, исходные контексты design/context/info-*.txt.
- Графика 404 — два оригинальных SVG; иконки карт 24 px экспортированы из 135:7210 и 135:7213 без изменения геометрии. Социальные иконки, шапка и футер переиспользованы.
- Пользователь подтвердил владельца: **ИП Бугаев Марк Александрович**. В едином тексте src/data/privacy.json заменён ИП Смоляр из Desktop-макета. Mobile-макет содержит другую организацию и старый текст про ЕГАИС; поэтому на обеих версиях используется Desktop-текст с подтверждённым владельцем. Все девять разделов сверены с исходником; остальные формулировки не редактировались. Это перенос текста, не юридическая проверка и не подтверждение фактических процессов обработки данных.
- Пользователь подтвердил адрес: **Витебск, проспект Московский, 111**; карточек организации на картах пока нет. По его поручению карта-заглушка Санкт-Петербурга заменена живым виджетом Яндекс Карт по адресу. В браузере проверен найденный дом 111 и масштаб 16. Внешняя ссылка расположена под виджетом, чтобы не закрывать управление или атрибуцию. Виджет требует интернета.
- [Документация виджета Яндекс Карт](https://yandex.ru/support/maps/ru/concept/get-map-reference.html). После создания карточки организации заменить адресный поиск на её ссылку в src/data/footer.ts. Google Maps также использует адресный поиск; точные координаты вручную не задавались.
- В Desktop контактов отдельные телефоны отсутствуют в макете — они доступны в шапке и футере. На Mobile дополнительный блок телефонов сохранён. Неподтверждённые социальные ссылки остаются отключёнными.
- Пункт «Контакты» в обеих шапках и футере ведёт на /contacts/. Политика конфиденциальности подключена в общих футерах. Отдельная политика обработки персональных данных не подменяется этой страницей и остаётся неподключённой.
- В 404 работает возврат на главную. Astro отдаёт HTTP 404 для несуществующего URL; после публикации требуется сохранить обработку 404 на выбранном хостинге.
