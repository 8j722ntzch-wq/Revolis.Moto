# BankCard — Desktop

Второй составной компонент перенесён из свежего контекста и снимка Figma `26:5495` от 21.10.2026. В витрине `/ui-kit/#bank-cards` показаны Альфа Банк, Технобанк и подбор условий оплаты — обычное состояние и наведение. Мобильные варианты не реализованы.

## API и данные

```astro
---
import BankCard from '../components/BankCard.astro';
import LeadDialog from '../components/LeadDialog.astro';
---
<BankCard id="finance-alfa" variant="alfa" dialogId="finance-dialog" />
<BankCard id="finance-techno" variant="technobank" dialogId="finance-dialog" />
<BankCard id="finance-help" variant="consultation" dialogId="finance-dialog" />
<LeadDialog id="finance-dialog" />
```

`id` уникален, `variant` обязателен. `terms` содержит подтверждённые `durationLabel` и `rateLabel`; без него банковская карточка пишет «Условия уточняются». `modelId` необязателен. `headingLevel` — h2/h3/h4, по умолчанию h3. Без `dialogId` или демонстрационного действия кнопка отключена. Указанный dialog должен присутствовать на той же странице. Оформление самого диалога — отдельный этап.

Кнопка передаёт общему LeadDialog `intent=finance`, `source=bank-cards`, банк `alfa` / `technobank` и необязательную модель. Подбор условий без выбранного банка очищает предыдущий выбор. Витрина использует `demoAction`: локально сообщает выбор и не открывает форму. `demoState="hover"` фиксирует состояние для сравнения.

Названия и оригинальные логотипы находятся в `src/data/finance.ts`. `bankCardsReference` — отдельные примеры из Figma со сроком до 12 месяцев и ставкой от 0,01 %. Они не являются подтверждёнными банковскими программами и не используются как значения по умолчанию. Перед сборкой секции финансирования нужны актуальные условия.

## Геометрия и переиспользование

| Элемент | Размер и положение внутри поверхности |
| --- | --- |
| Карточка | 288 × 174 px, radius 16 |
| Логотип Альфа Банка | 170 × 34 px, x20 / y20 |
| Логотип Технобанка | 248 × 34 px, x20 / y20 |
| Банковская кнопка | 40 × 40 px, x228 / y114; стрелка 20 × 20 |
| Текст подбора условий | x20 / y13, ширина 248 |
| Кнопка подбора | 248 × 42 px, x20 / y112; стрелка 16 × 16 |
| Наведение | подъём поверхности на 8 px |

Карточки построены на flex и общих токенах. Минимальная высота позволяет длинному содержимому увеличивать карточку без обрезки. Цвета: Альфа `#ef3124`, Техно `#052eb7`, подбор — общий Gray 6. При наведении и клавиатурном фокусе кнопки банков заполняются белым, кнопка подбора — фиолетовым. Длительность 140 ms и видимый фокус — технические дополнения; reduced motion сохранён.

Общий Button расширен `tone="inverse"` для outline S и icon M. Icon M сохраняет размер кнопки 40 px, но использует исходную стрелку 20 px и padding 10 px. Ранее перенесённый icon S остаётся 40 px со стрелкой 16 px. Другие сочетания inverse отклоняются. Pressed сохраняет оформление hover, поскольку отдельного pressed в этих карточках нет; disabled остаётся нативным.

Шесть SVG экспортированы целиком из исходных узлов: два логотипа и четыре стрелки. Временная ссылка Figma вернула HTML, поэтому использован Plugin API `exportAsync(SVG_STRING)`. Контуры не изменены, внутренние маски логотипов сохранены, intrinsic width/height не переопределяются. Реестр — `design/ui-assets.json`, измерения — `design/bank-card.json`.

## Проверка

На 1366 / 1470 / 1920 px все шесть карточек — 288 × 174 px, контейнер 1224 px, горизонтального переполнения и незагруженных изображений нет. Размеры и позиции логотипов, кнопок и стрелок сверены со снимком и свойствами Figma. Общий icon S сохранил геометрию. Небольшие различия ширины текста и дробных высот строк связаны с локальным Inter Variable: строгая пиксельная идентичность не заявляется.

Enter работает для всех трёх действий. Проверены контекст банка/модели в существующем диалоге, сброс выбора при общем подборе, закрытие Escape и возврат фокуса. Без условий нет примерной ставки, без действия кнопка disabled. Отправка заявки остаётся отключённой без backend и политики.

Astro check (22 файла) и сборка двух страниц проходят без ошибок. Автономное превью проверено браузером: все изображения встроены, внешний CSS/JS отсутствует, шрифт загружен, выбор банка работает.
