- Шапки всех страниц, Hero и финальная консультация → lead-dialog.
- Тест-драйв → lead-dialog с intent=test-drive; контекст отличается от консультации.
- Банковские карточки → bank-dialog с предварительным выбором Alfa/Technobank. Общий подбор очищает выбор; radio позволяет изменить банк. Модель, intent и источник передаются в payload.

- Закрытие крестиком, Escape и по фону; фокус возвращается на кнопку. Мобильное меню закрывается перед открытием формы. Прокрутка фона блокируется, нативный dialog удерживает клавиатурный фокус.
- Поля сохраняются при закрытии; при успешной отправке сбрасываются. Повторная отправка блокируется, ошибки не открывают благодарность. Анимация учитывает reduced motion. Прогресс в благодарности декоративный, не изображает процент работы сервера.
