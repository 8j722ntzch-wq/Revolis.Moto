# SiteHeader — Desktop

Источник: Figma `1:8464`, Desktop `1:8465`; свежий контекст и снимок получены 21.10.2026. Реестр измерений и проверки — `design/site-header.json`.

Шапка высотой 64 px, контейнер 1224 px, обычный поток документа. Логотип, телефон, пять ссылок и solid-кнопка S без стрелки. Использует общие Button и токены. Sticky, тень и мобильные варианты не добавлены.

Оригинальный логотип `1:8475` целиком экспортирован в `public/assets/site/logo.svg`. Логическая рамка 116 × 36 px, SVG 122 × 38 px с исходным viewBox; рисованная область выступает влево на 5,75390625 px. Смещение сохранено без изменения путей и растяжения.

## Подключение

```astro
---
import SiteHeader from '../components/SiteHeader.astro';
import LeadDialog from '../components/LeadDialog.astro';
---
<SiteHeader dialogId="lead-dialog" />
<LeadDialog id="lead-dialog" />
```

`dialogId` должен соответствовать размещённому на странице LeadDialog. CTA передаёт `intent=consultation`, `source=header`; банк и модель очищаются. Без dialogId кнопка отключена. `demoAction` используется только витриной с её локальным обработчиком; не означает отправку заявки.

`links` переопределяет адреса пяти исходных пунктов; размеры колонок рассчитаны на подписи из макета. `homeHref` по умолчанию `/`. `phone` задаёт подпись и адрес типа `tel:`. Общие данные — `src/data/navigation.ts`.

Адреса `/#models`, `/#about`, `/#finance`, `/#faq`, `/#contacts` — контракт будущих секций главной. Сейчас главная не собрана; в витрине переданы существующие цели. Телефон +375 (25) 971-19-02 взят из Desktop-макета и требует подтверждения перед публикацией.

При 1470 px координаты логотипа x123, телефона x331, навигации x747, CTA x1203 совпадают с источником; CTA 145 × 42 px. Дробная высота текста браузера 18,1875 px против округлённых 18 px Figma.

Проверены существование всех целей витрины, переход к банкам, tel-адрес, демонстрационный отклик CTA, открытие существующего диалога через Enter, контекст consultation/header, закрытие Escape и возврат фокуса. Отправка отключена без backend и политики. Оформление диалогов — следующий шаг.

`npm run check`: 24 файла, без ошибок, предупреждений и подсказок. `npm run build`: две страницы. Автономное превью обновлено; раздел «Шапка».
