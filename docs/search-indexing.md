# Публичные маршруты и sitemap — 26.10.2026

По поручению владельца страницы UI Kit исключены из публичных сборок. Исходники перенесены в `src/internal/`, маршруты `/ui-kit/` и `/ui-kit-mobile/` подключаются интеграцией только для `astro dev`. Обычная сборка, релизная сборка и их статический preview не содержат этих HTML. Компоненты сайта сохранены. Готовые HTML-витрины удалены из текущей ветки; повторный экспорт UI Kit отключён, файлы витрин игнорируются Git.

Это разделение маршрутов, не система авторизации. Локальный dev-сервер не следует публиковать через туннель или запускать на внешнем интерфейсе. GitHub-репозиторий сейчас публичный: исходники и история доступны через GitHub. Эта задача не меняет видимость репозитория и не переписывает историю. Для конфиденциальности исходников потребуется отдельно сделать репозиторий приватным.

## Режимы

| Команда | Индексация | Sitemap | UI Kit |
| --- | --- | --- | --- |
| `npm run dev` | noindex | Без URL | Только локально |
| `npm run build` | noindex; robots Disallow / | Без URL | Нет |
| `npm run build:release` | index/follow для 10 основных страниц | 10 канонических URL | Нет |

База адресов — `https://revolis.by`. Sitemap генерируется в `/sitemap.xml` из единого списка `src/lib/seo.ts`: главная, каталог, контакты, семь зарегистрированных SKU. Добавление модели в реестр автоматически меняет карту и правила индексации. Включены только абсолютные канонические URL без параметров; у каталожных фильтров canonical указывает на `/models/`. Desktop/Mobile используют один адрес. `lastmod`, `priority` и `changefreq` не выдумываются.

Политика конфиденциальности доступна пользователям, но остаётся noindex и вне карты; 404 тоже исключена. В release robots разрешает обход и указывает Sitemap. Обычная сборка сохраняет запрет обхода и noindex, чтобы предпросмотр не индексировался. Пустая карта обычной сборки намеренная: индексируемых страниц в этом режиме нет.

## Публикация

Штатный workflow master теперь вызывает `npm run build:release`. Проверка `scripts/check-public-build.mjs` останавливает сборку при лишних маршрутах UI Kit, расхождении sitemap/robots/canonical или noindex на основных релизных страницах. Перед каждой сборкой очищается только генерируемый `dist/`, чтобы старые маршруты не остались в каталоге загрузки.

После успешной загрузки и сверки файлов SFTP-workflow перемещает существующие на хостинге директории `ui-kit` и `ui-kit-mobile` в резервную копию за пределами document root. Тип директорий проверяется через lstat; символические ссылки и неожиданные типы останавливают операцию. Прочие старые файлы этим шагом не удаляются. Изменение выполнится только при будущем согласованном релизе; текущий хостинг в этой задаче не изменялся. Исторический workflow загрузки фиксированного старого master не следует повторять: он способен вернуть прежнюю заглушку и UI Kit.

После релиза проверить HTTP 404 для обеих библиотек, HTTPS/редиректы и основной домен, доступность `/sitemap.xml` и `/robots.txt`, затем добавить sitemap в Google Search Console и Яндекс Вебмастер. Отсутствие HTML в сборке не подтверждает удаление старых копий с хостинга до выполнения релиза. Поисковая индексация не гарантируется наличием карты.
