# SiteFooter — Desktop

Источник: `1:8514`, Desktop `1:8515`, 21.10.2026. Реестр: `design/site-footer.json`. Высота 510 px, контейнер 1224 px. Grid и flex сохраняют макет без абсолютного позиционирования блоков. Button переиспользован для навигации, телефонов, карт, политик и возврата наверх. Семь оригинальных SVG сохранены без перерисовки, включая Instagram hover.

## API

```astro
---
import SiteFooter from '../components/SiteFooter.astro';
---
<SiteFooter />
```

На странице необходим элемент `id="top"`; либо передать `topHref`. `links` задаёт навигацию; по умолчанию используются общие адреса будущих секций главной. `content` переопределяет данные из `src/data/footer.ts`.

`destinations` принимает подтверждённые URL: `yandex`, `google`, `instagram`, `telegram`, `youtube`, `privacy`, `personalData`. Без адреса соответствующий элемент отключён. `demoAction` используется только витриной, где её обработчик объясняет отсутствие адреса. Никаких случайных профилей и фиктивных документов не добавлено. Внешние карты и соцсети открываются в новой вкладке с noopener/noreferrer; политики — обычные ссылки.

## Сверка

На ширинах 1366 / 1470 / 1920: высота 510 px, контейнер 1224 px, переполнения нет. При 1470 px: контакты x435/y128, кнопка наверх x1169/y40, соцсети x1179/y332, реквизиты y404, политики y456. Все SVG загружены; карты 18 × 18, стрелка 16 × 16, социальные иконки 24 × 24 внутри кнопок 48 × 48 px.

Высоты строк меток, адреса и реквизитов округлены к рамкам Figma (18, 38, 14 px), чтобы браузерные дроби не увеличивали футер. Исходные шрифтовые веса сохранены. Витрина проверена: навигация к моделям, Enter на возврате наверх, пояснение для отсутствующей ссылки. Astro check: 26 файлов, без ошибок/предупреждений; build: две страницы.

Instagram hover использует исходный фиолетовый SVG `108:4680`. Figma-прототип соцкнопки переключает и Telegram/YouTube в Instagram: эту подмену бренда не переносили; их исходные иконки сохранены, доступен клавиатурный фокус.

## До публикации

Контакты, адрес и график сохранены буквально: «Пн, Пт», 18:00–20:00. Это не подтверждение актуальности. Строка торгового реестра в источнике заканчивается двоеточием без данных. Нужны подтверждённые реквизиты, график, адрес и URL. Низкий контраст второстепенного текста сохранён по макету; отдельную проверку доступности это не заменяет. Мобильный вариант и диалоги в этот шаг не входят.
