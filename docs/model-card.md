# ModelCard — Desktop

Перенесён первый составной компонент: Figma `19:4818`, обычное состояние `19:4501`, наведение `19:4819`. Свежий контекст и снимок получены 21.10.2026. Витрина: `/ui-kit/#model-cards`, раздел 09. Мобильные варианты в этот шаг не входят.

## Использование

```astro
---
import ModelCard from '../components/ModelCard.astro';
import { models } from '../data/catalog';
---
{models.map(model => <ModelCard id={`catalog-${model.id}`} model={model} />)}
```

`id` должен быть уникальным; он связывает article с заголовком. `headingLevel` принимает h2/h3/h4, по умолчанию h3. Данные хранятся в `src/data/catalog.ts`. Для витрины доступны `demoState="hover"` и `demoAction`; обычное использование их не требует.

Карточка переиспользует Button и StatusBadge. Переход появляется только при `pageReady: true`; иначе кнопка отключена. `demoAction` включает локальный отклик витрины без перехода. Неизвестная цена отображается как «Цена уточняется», неизвестное наличие и регистрация скрыты. При отсутствии фотографии отображается текстовое сообщение. Условия финансирования выводятся только из переданного `financeLabel`.

## Соответствие макету

| Элемент | Размер / поведение |
| --- | --- |
| Карточка | 392 × 642 px, padding 16, radius 16 |
| Область изображения | 360 × 320 px, radius 12, белый фон |
| Фото | 320 × 213 px, центр с вертикальным смещением 0,5 px |
| Контент | 360 × 278 px, основной интервал 20 px |
| Иконки характеристик и регистрации | исходные 24 × 24 px |
| Кнопка | общая solid S со стрелкой, 360 × 42 px |
| Наведение | подъём поверхности на 8 px, тёмно-фиолетовая кнопка |

Высота 642 px — минимальная: более длинный подтверждённый контент может увеличить карточку. Фокус клавиатуры также поднимает карточку; переход 140 ms отключается общей настройкой reduced motion. Эти доступные состояния дополняют макет. Подзаголовок использует настоящее локальное Inter Medium Italic.

Четыре новые SVG экспортированы из исходных узлов без изменения геометрии. PNG 640 × 426 px экспортирован в масштабе 2× только из слоя фотографии `72:6737`, сохраняя кадрирование Figma. Это изображение, а не снимок интерфейса. Оригинальные status/arrow уже доступны через общие компоненты. Полный маппинг: `design/ui-assets.json`; измерения: `design/model-card.json`.

## Наполнение и проверка

В шаблоне Figma название Hammer Touring 200 соседствует с характеристикой 300 см³, примерной ценой 34 500 BYN и статусом наличия. Они сохранены только в отдельном `modelCardReference` для визуального сравнения. Массив семи моделей каталога не изменён; коммерческие данные и соответствие фотографии модели требуют подтверждения перед подключением к каталогу.

В браузере проверены 1366 / 1470 / 1920 px: карточка 392 × 642, медиа 360 × 320, фото 320 × 213, CTA 360 × 42; горизонтального переполнения и незагруженных изображений нет. Проверены Enter, Tab, фокус, подъём и сброс состояния, отклик демо-кнопки, отключённый переход для неготовой страницы и сформированный href при `pageReady: true`. Данные с null не создают цену, наличие или условия финансирования.

Сохраняются небольшие различия рендеринга Inter Variable: дробные высоты строк браузера дают смещение до 0,5 px внутри текстовых групп. Внешняя геометрия и положение кнопки совпали. Строгая пиксельная идентичность не заявляется.

Проверки Astro (20 файлов, без ошибок), сборка двух страниц и три существующих теста маски проходят. Автономное HTML-превью проверено браузером: изображения и курсив встроены, внешних CSS/JS нет, кнопка даёт локальный отклик.
