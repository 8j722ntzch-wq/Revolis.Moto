# Desktop UI foundation — 21.10.2026

Библиотека переносит существующий дизайн Figma в переиспользуемые Astro-компоненты. Страница `/ui-kit/` служит для проверки состояний и состава; её презентационная композиция и демонстрационные тексты не являются дизайном главной.

Все иконки сохранены как оригинальные SVG. Сначала Figma вернула временные URL, но их загрузка дала HTML вместо изображений; использован прямой `exportAsync({format: 'SVG_STRING'})` исходных узлов. Геометрия SVG не перерисовывалась. Реестр: `design/ui-assets.json`. Inter Variable 5.3.0 поставляется локально через Fontsource; лицензия — `docs/inter-license.txt`.

## Правила использования

Импортировать компоненты из `src/components/ui/`. Базовый layout уже подключает шрифт и общие стили. Общие изменения вносить в токены/компоненты, не копировать их оформление в секции. Семантика заголовка задаётся отдельно от визуального размера. Кнопка с `href` — ссылка; без `href` — button. `disabled` отключает взаимодействие, включая ссылки. Значения `data-demo-state` используются только в витрине состояний.

```astro
---
import Button from '../components/ui/Button.astro';
import SectionHeading from '../components/ui/SectionHeading.astro';
---
<SectionHeading eyebrow="НАША ТЕХНИКА" title="Квадроциклы для ваших задач" />
<Button arrow data-open-lead="lead-dialog" data-source="models">Оставить заявку</Button>
```

Размеры solid/outline кроме S и стрелки кроме S не реализованы: компонент явно отклоняет неподдерживаемые комбинации. Для новых вариантов сначала получить соответствующий Figma-контекст. Телефон — `type="tel"`; маска не добавлена автоматически.

## Сверка источника

- Подпись «P1 — 18» расходится с фактическими 20 px. Взяты 20 px.
- Второй образец с подписью Purple привязан к Red2 `#b42115`. Он не использован как hover: фактический hover кнопки — `#2e1854`.
- Радиус 4 px в таблице не заменяет фактический радиус кнопок 10 px.
- Заголовок Hero — 64 px / 900 / 110%, а не основной заголовок секции 40 px.
- Фокус клавиатуры и длительность переходов 140 ms — технические дополнения; их нет в измеренных токенах Figma. Учитывается `prefers-reduced-motion`.

## Проверка

`npm run check` и `npm run build` проходят. Проверены реальные действия кнопки, ввод, checkbox, ошибочное поле, раскрытие FAQ мышью и Enter, автоматическое закрытие предыдущего вопроса. Отправка LeadForm без endpoint и политики отключена.

Проверка выполнена в браузере с iframe соответствующей ширины; полоса прокрутки занимает 15 px. Небольшое различие собственной ширины текста сохраняется: CTA без иконки примерно 143,7 px вместо 145 px в Figma. Исходный бинарный файл шрифта Figma не предоставлен; строгая пиксельная идентичность не заявляется. Высоты, цвета, интервалы и исходные размеры SVG сверены с полученным контекстом.
