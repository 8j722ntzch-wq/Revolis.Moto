## Правила использования

Импортировать компоненты из `src/components/ui/`. Базовый layout уже подключает шрифт и общие стили. Общие изменения вносить в токены/компоненты, не копировать их оформление в секции. Семантика заголовка задаётся отдельно от визуального размера. Кнопка с `href` — ссылка; без `href` — button. `disabled` отключает взаимодействие, включая ссылки. Значения `data-demo-state` используются только в витрине состояний.

```astro
---
import Button from '../components/ui/Button.astro';
import SectionHeading from '../components/ui/SectionHeading.astro';
---
<SectionHeading eyebrow="НАША ТЕХНИКА" title="Квадроциклы для ваших задач" />
<Button arrow data-open-lead="lead-dialog" data-source="models">Оставить заявку</Button>
```

Размеры и сочетания, отсутствующие в текущей библиотеке Desktop, отклоняются компонентом. Для `variant="icon"` обязателен `aria-label`. В Figma для Text XS и Text (Bold) L есть только default/hover: витрина не выдаёт остальные состояния за перенесённые варианты. При фактическом disabled сохраняется нативное отключение действия.

Телефон — нативный `type="tel"` с маской `+375 __-___-__-__` из текущих состояний Figma. При наведении виден шаблон, при фокусе — редактируемая маска, после ухода фокуса пустой шаблон исчезает. Ввод, выделение, удаление и вставка обрабатываются общим модулем `src/lib/phone-mask.ts`; HTML `pattern` требует полный номер. Это формат белорусского номера, заданный макетом, а не универсальная международная маска.

У `SectionHeading` удалён неподтверждённый размер `lg`; перенос строки в `title` сохраняется. Варианты заголовка с кнопкой/слайдером пока не перенесены.

- Таблица типографики обновлена: H1/H2 Bold, H3 28 px Bold, H4 24 px Semi Bold, H5 20 px Bold/Semi Bold, H6 16 px Bold, H7/H8 Bold/Semi Bold. P1 теперь корректно подписан как 20 px.

- Радиус 4 px относится к checkbox и статусам; у кнопок и полей — 10 px.
- SectionHeading по-прежнему использует 40 px / 600, хотя фундаментальный H1 — 40 px / 700. Эти роли разделены.
- Заголовок Hero — 64 px / 900 / 110%, а не основной заголовок секции 40 px.
- Фокус клавиатуры и длительность переходов 140 ms — технические дополнения; их нет в измеренных токенах Figma. Учитывается `prefers-reduced-motion`.
