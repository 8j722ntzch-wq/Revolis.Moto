# Главная Desktop

Собрана из текущего `Main (Desktop)_1470 px`, Figma `1:13203`, 2026-10-21. Маршрут `/`; офлайн-превью `preview/Revolis_Moto_Homepage.html`. Работа ведётся в development, сайт не опубликован.

Все 11 секций получили свежий high-fidelity context и визуальный референс: шапка, первый экран, модели, краткие преимущества, финансирование, тест-драйв, документы, прокат, консультация, FAQ, футер. Источники: `design/figma-source.json`, `design/context/home/`, `design/assets.json`. Все фотографии, иллюстрации и пиктограммы оригинальные. В макете пустое поле карточки «Прозрачные поставки» сохранено. Документы перенесены с исходными размытиями.

Повторно используются SiteHeader, SiteFooter, ModelCard, BankCard, Button, SectionHeading и FaqItem. Новые секции находятся в `src/components/home/`, общие стили страницы — `src/styles/home.css`. AdvantageItem повторно используется для преимуществ и адресов. ModelCard получил необязательную высоту фотографии; SectionHeading — слот цветного заголовка; BankCard — текст описания и адрес действия. Прежние значения компонентов в UI Kit сохранены.

## Поведение текущего этапа

- Навигация, «Смотреть модели», переход к контактам и возврат наверх работают по якорям; телефоны используют tel:.
- До появления макетов диалогов консультационные кнопки ведут к контактам. Ни форм, ни отправки заявок здесь нет.
- Отдельные страницы моделей и каталог — следующий этап: кнопки отключены с сохранением исходного внешнего вида.
- Адрес Instagram проката в Figma не задан; кнопка отключена. URL карт, соцсетей и политик футера также требуют подтверждения, как и ранее.
- В текущих экземплярах FAQ есть только вопросы. Ответы не выдуманы; отображаются пять закрытых строк. FaqItem сохраняет готовое доступное раскрытие для момента, когда появятся ответы.
- Цены, наличие, спецификации и банковские условия воспроизводят Figma. Три модели вынесены в `homepageModelReferences` и не изменяют неподтверждённый production-массив `models`.
- Мобильная версия и всплывающие окна в этот этап не входят.

## Проверка

`npm run check`, `npm run build`, `npm run design:check`. В браузере проверены ширины 1366, 1470 и 1920 px: контейнер 1224 px, горизонтального переполнения нет. При 1470 px измерены позиции секций: 0, 64, 856, 1754, 1986, 2400, 3008, 3918, 4574, 5134, 5726; общая высота 6236 px. Геометрия совпадает с исходным фреймом. Проверены оригинальные изображения, переходы по якорям и к контактам. Ширины меньше 1288 px ожидают отдельный мобильный макет.

`npm run export:homepage` создаёт автономный HTML из собранной страницы, встраивает стили, шрифты и изображения и сохраняет якорную навигацию. Для обновления сначала выполнить сборку.

## Исправления интерфейса — 21.10.2026

- Text S в хедере сохраняет Semibold (600) при наведении, как в обновлённой Figma.
- Наведение на карточку главной включает Hover кнопки «Перейти к модели», даже пока переход отключён. Доступность маршрута не изменена.
- Общий display:block для изображений больше не раскрывает скрытые цветовые варианты стрелок. На каждой кнопке виден один нужный SVG, оригинальная геометрия сохранена.
- PNG иллюстрации проката заменён двумя исходными SVG-слоями Figma (контур и цветная графика), без вложенных растров. Контейнер 496 × 496 px и положение сохранены; описание исправлено на «Зубр и аист».

Проверены Astro check (0 ошибок/предупреждений), сборка, комплектность исходников и браузер: Hover Text = 600, реакция карточки, единственный видимый вариант стрелки, загрузка SVG. На ширинах 1366/1470/1920 px проверены контейнер 1224 px, размеры новых слоёв и отсутствие горизонтального переполнения; блок проката сопоставлен с актуальным референсом. Мобильная версия в эту проверку не входила.
