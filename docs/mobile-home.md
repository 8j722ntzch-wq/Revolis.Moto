# Мобильная главная — 21.10.2026

Пользователь разрешил сборку после проверки мобильной библиотеки. Главная `/` теперь адаптивная; используются существующие секции и данные, MobileHeader и мобильные варианты компонентов. Источник — Main (Mobile)_390 px, Figma 1:13204, файл JkXOsnFvWZmMab1VYjVQAJ. Свежие high-fidelity контексты десяти секций сохранены в design/context/mobile-home, реестр — design/mobile-home.json.

Мобильный layout действует до 1287 px: это граница минимальной ширины существующей desktop-композиции, а не дополнительный breakpoint из Figma. При 390 px контейнер 340 px; на более широких экранах растёт до 600 px. На 320–374 px боковые поля 16 px. Desktop сохраняет прежнюю композицию от 1288 px.

Каталог и документы используют горизонтальную прокрутку со scroll-snap; области доступны с клавиатуры. Высота ряда моделей определяется самой высокой карточкой: у BaltMotors двухстрочное описание, поэтому ряд на ~18 px выше фиксированного фрейма Figma. Контент не обрезается. Мобильные фото/декор/иконки — оригиналы, без перерисовки. Иконки гарантии и безопасности получены повторно из конкретных instance-слоёв: общий контекст ошибочно возвращал вместо них другой glyph. Существующие оригиналы моделей, банков, документов и рукописной подписи переиспользованы. SVG сохраняют внутреннюю геометрию.

Шапка закреплена, меню использует native dialog с Escape, возвратом фокуса, закрытием после перехода и при переключении на Desktop. Якоря учитывают шапку; высокий мобильный блок финансов открывается с начала. FAQ сохраняет утверждённые ответы, плавное раскрытие и reduced-motion. Неподтверждённые ссылки и страницы моделей остаются отключёнными. CTA ведут к контактам; диалоги и backend не входят в этап.

Проверка: Astro check/build/design:check; браузерные ширины 320/360/390/430/768/1024/1287/1366/1470/1920 без горизонтального переполнения страницы, навигация, меню, горизонтальное листание и FAQ. На 390 px секции визуально сопоставлены со скриншотами Figma. Переносы текста могут отличаться из-за шрифтового рендеринга. Физические iOS/Android не проверены. Офлайн-превью главной регенерируется командой npm run export:homepage; мобильной библиотеки — npm run export:mobile.
