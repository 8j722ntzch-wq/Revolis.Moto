## Репозиторий и порядок работы

Основной репозиторий: https://github.com/8j722ntzch-wq/Revolis.Moto

- Старая `main` сохранена и не используется в этом процессе.

## Посмотреть результат

Открыть `preview/Revolis_Moto_UI_Kit.html` в браузере: это автономное Desktop-превью со встроенными шрифтами, изображениями и интерактивными состояниями; ModelCard находится в разделе «Техника», BankCard — «Банки», SiteHeader — «Шапка». Для разработки — маршрут `/ui-kit/`.

```sh
npm ci
npm run dev
npm run check
npm test
npm run build
npm run export:ui-kit
```

Нужен Node.js 22.22+; проверка выполнена на Node.js 24. Статическая сборка сохраняется в `dist/`, автономное превью — в `preview/`. Для dev-превью разрешён hostname `terminal.local`; это не production-домен.

- Токены цветов, размеров шрифта, начертаний, отступов, контейнера и радиусов.
- Локальный Inter Variable с кириллицей и курсивом; 26 оригинальных SVG и фото PNG из Figma.

- Витрина состояний: default, hover, pressed, disabled, заполнение и ошибка; клавиатурный фокус.

- Реестры исходных узлов, локальные контексты и документация продолжения.

Подробности, ограничения и API: `docs/ui-foundation.md`. Состояние переноса: `design/ui-foundation.json`; ModelCard: `docs/model-card.md`; BankCard: `docs/bank-card.md`; SiteHeader: `docs/site-header.md`; оригинальные ресурсы: `design/ui-assets.json`.

## Проверено

`npm run check`: без ошибок, предупреждений и подсказок. `npm run build`: успешная сборка. В браузере проверены ввод и состояния, кнопки, checkbox, FAQ мышью и клавиатурой. На ширинах 1366 / 1470 / 1920 px контейнер — 1224 px, горизонтального переполнения нет, изображения загружаются. ModelCard — 392 × 642 px, фото — 320 × 213 px; проверены подъём на 8 px, клавиатура и обработка неподтверждённых данных.

Это проверка библиотеки, а не завершённое сравнение всей главной. Возможны небольшие различия ширины текста из-за версии и рендеринга шрифта. BankCard проверена вместе с передачей банка в существующий диалог; отправка заявок не подключена. Мобильная композиция не реализована.

## Подключение формы

В `.env` задать `PUBLIC_LEAD_ENDPOINT=/api/leads` и передать LeadForm действующий `policyUrl`. Серверный обработчик необходимо реализовать отдельно: в статической сборке его нет. Без endpoint или политики кнопка отправки отключена.

Обработчик проверяет входные данные, согласие, допустимые источники и модели, ограничивает частоту запросов и передаёт заявку в согласованный канал. Успех — JSON `{ "ok": true }` после подтверждённого приёма; ошибки — соответствующий HTTP-статус. Клиент принимает только адрес того же origin. Секреты не добавляются в клиентский код, контакты не сохраняются в localStorage или аналитике.
