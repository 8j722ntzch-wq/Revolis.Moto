# Revolis.Мото — сайт на Astro

Обновлено 21.10.2026. **Десктопная главная собрана; сайт находится в разработке.** Мобильная версия, страницы моделей, диалоги и приём заявок не завершены. Локальный запуск не означает публикацию сайта.

## Начать работу

Агенту: прочитать [AGENTS.md](AGENTS.md), [статус и ограничения](docs/project-status.md), [бриф](docs/implementation-brief.md) и [порядок работы с Figma](docs/figma-handoff.md).

Нужен Node.js 22.22+ и npm. Установка по зафиксированному package-lock.json:

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

Открыть адрес из вывода сервера (обычно http://127.0.0.1:4321/). Главная — `/`, библиотека компонентов — `/ui-kit/`. Если сервер уже работает, использовать его адрес. В Astro 7 команды `astro dev status`, `astro dev logs`, `astro dev stop` позволяют управлять фоновым сервером; запускать через локально установленный Astro.

Без сервера можно скачать и открыть `preview/Revolis_Moto_Homepage.html`; витрина компонентов — `preview/Revolis_Moto_UI_Kit.html`. Это снимки сборки, их нужно обновлять после изменений интерфейса.

## Что реализовано

11 секций главной по Figma; переиспользуемые UI-компоненты, ModelCard, BankCard, SiteHeader и SiteFooter; оригинальные ресурсы, локальный Inter Variable, якорная навигация и телефонные ссылки. Подробности поведения — [главная](docs/homepage.md), [UI foundation](docs/ui-foundation.md).

Форма и диалог существуют как компоненты, но на главной не подключены. Консультационные кнопки ведут к контактам. Неизвестные ссылки отключены, FAQ содержит пять ответов пользователя и плавно раскрывается мышью или клавиатурой (320 мс, с поддержкой reduced motion). Данные демонстрации Figma отделены от подтверждённого каталога.

## Проверки

```sh
npm run design:check
npm run check
npm test
npm run build
npm run export:homepage
npm run export:ui-kit
```

`design:check` проверяет комплектность локальных исходников, а не визуальную точность. Сборка не подтверждает работу заявок и готовность к публикации. Проверять страницу при 1470 px по Figma, затем Desktop при 1366 и 1920 px. Мобильную главную проверять при 390 px и на узких экранах; подробнее в docs/mobile-home.md.

## Источники и заявки

[Figma: главная](https://www.figma.com/design/JkXOsnFvWZmMab1VYjVQAJ/?node-id=1-13203), снимок 21.10.2026: 1470 × 6236 px, контейнер 1224 px. Реестры — `design/figma-source.json` и `design/assets.json`.

Для будущего подключения LeadForm нужны подтверждённый `policyUrl` и `PUBLIC_LEAD_ENDPOINT` того же origin. Серверного обработчика в статической сборке нет. Он должен проверять данные и согласие, ограничивать частоту запросов и подтверждать реальный приём через JSON `{ "ok": true }`. Секреты не помещать в клиентский код. Контакты не сохранять в localStorage и аналитике.

Шапка главной остаётся сверху при прокрутке; якорная навигация учитывает её высоту. Панель Astro доступна только при разработке.

Переходы к разделам главной плавные; при системном уменьшении движения прокрутка мгновенная.

На Desktop переход «Кредиты и рассрочки» центрирует блок под шапкой; на мобильном показывает начало более высокого блока.

Мобильные стили и компоненты: `/ui-kit-mobile/`, [описание](docs/mobile-ui.md). Адаптивная главная доступна на `/`; [описание мобильной сборки](docs/mobile-home.md).
